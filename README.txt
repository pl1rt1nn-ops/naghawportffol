NAGHAW STUDIO — FULL REMAKE

Static build: no npm / Node.js required.

Features:
- Liquid Glass UI with red/black visual system.
- Animated background, glow, glass panels and responsive layout.
- Registration/login.
- Naghaw is free on the first launch; the first registration of Naghaw reserves the nickname.
- Case-insensitive nickname uniqueness.
- Library with Play and ZIP download after activation.
- FREE / GIFT / DEV activation codes.
- Admin generator creates cryptographically-looking random codes using an allowlist of letters/numbers and checks collisions.
- Admin can enable/disable/delete codes and set activation limits.

IMPORTANT:
This is a static frontend. Accounts, sessions and codes are stored in browser localStorage. This is not a secure shared server database. Anyone who can edit browser storage can bypass it. For production-grade accounts/payments/download protection, connect a real backend/database.
