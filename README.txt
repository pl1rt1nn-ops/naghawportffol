Naghaw Studio Static V6
Без npm/Node.js.
Ник Naghaw свободен при первом запуске. Первый пользователь, зарегистрировавшийся именно как Naghaw, становится владельцем ника. После этого любые варианты Naghaw/naghaw/NAGHAW запрещены другим пользователям.
Данные этой статической версии хранятся в localStorage и не являются общей серверной базой.
