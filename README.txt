NAGHAW STUDIO — FULL STATIC BUILD
Без npm / Node.js.
Первый запуск: ник Naghaw свободен. Первый пользователь, зарегистрировавший Naghaw, закрепляет его за собой. Другие варианты NAGHAW/naghaw считаются занятыми.
Админка доступна владельцу Naghaw.
Коды FREE/GIFT/DEV и библиотека работают через localStorage. Это демо-режим: данные не являются общей серверной базой между посетителями. Для настоящих аккаунтов нужен backend.
